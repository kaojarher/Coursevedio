課程影片產線規劃器

專案

資料自動存於本機瀏覽器，也可匯出成 JSON 檔備份或換電腦使用。

AI 設定

可選 Puter AI，或自己選擇本機 LLM（Ollama、LM Studio 等）。API 金鑰只存在本機，匯出 JSON 時不會包含。

產線工具

講稿到合成的各環節，勾選代表該環節需付費。

一鍵產生影片

依分鏡順序自動補講稿、生圖、配音，再在瀏覽器內合成為 WebM 影片。生圖與配音使用 Puter；錄製期間請保持此分頁在前景。

3D 講師會隨配音音量張嘴，並眨眼、輕微擺動。分鏡的「講師動作」若含「揮手」或「點頭」，會觸發對應動作。VRM 檔不會存檔，重新開啟頁面需再選一次。
