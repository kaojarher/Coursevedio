AI 設定

可選 Puter AI（免 API Key），或自己選擇本機 LLM（Ollama、LM Studio 等）。API 金鑰只存在本機，匯出 JSON 時不會包含。

錄製與播放教學影片（內建 3D 講師與完整中文配音）

操作步驟：① 按「開始錄製」，在分享視窗選好要錄製的畫面（建議「此分頁」）並勾選音訊（本機語音請選整個螢幕並勾選系統音訊）→ ② 設定完成後自動全螢幕播放（預設為滿版畫面，不會改變擷取尺寸，錄影最穩定；準備素材的畫面也會被錄進去，想省掉可先按一次「▶ 播放」讓素材快取）→ ③ 播放結束自動停止錄製並下載。播放中按 Esc 可中止。也可以單獨按「▶ 播放」預覽。
